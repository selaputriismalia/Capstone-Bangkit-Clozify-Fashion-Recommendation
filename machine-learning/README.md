# Clozify Machine Learning

This folder contains a portfolio copy of selected machine-learning files from the original team repository: [C242-PS413/Clozify-ML](https://github.com/C242-PS413/Clozify-ML).

## Included

- Mood detection notebooks, including `Mood_modelling.ipynb` and `Apply-model.ipynb`
- Sample image used for mood-detection experiments
- Data-cleaning notebook
- Emotion/color mapping CSV files
- Embedding extraction notebook
- Team README and supporting documentation

## Not yet included

The full model and several larger data/artifact files have not been copied into this portfolio repository. This includes the trained `my_model.h5` model, large outfit dataset CSVs, and the full `Recommendation_system.ipynb` notebook. Some checkpoint notebooks may also be omitted.

Notebook execution may require the original datasets, trained model, external services, and dependency versions. The notebooks are included for source review and project documentation; they have not been executed or validated in this portfolio copy.
