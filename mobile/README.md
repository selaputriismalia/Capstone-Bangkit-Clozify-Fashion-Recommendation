# Clozify Android Application

Source repository: [C242-PS413/Clozify-MD](https://github.com/C242-PS413/Clozify-MD)

This folder documents the Android component of the Bangkit Academy 2024 Capstone Project, Clozify. The original project uses Kotlin, Retrofit, CameraX, and an MVVM-style structure.

## Source and attribution

The Android source code remains in the original team repository linked above. This portfolio repository is maintained to document Sela Putri Ismalia's project experience, with a focus on the Cloud Computing learning path. Please refer to the original repository for the complete Android Studio project and its history.

## Run the app

1. Open the original `Clozify-MD` repository in Android Studio.
2. Allow Gradle sync to complete.
3. Configure any required API/backend endpoints for your environment.
4. Run on an Android device or emulator. Camera features require camera permission and a compatible device/emulator.

The Android source has not been duplicated into this folder yet; this README is a pointer to the original complete source so this portfolio does not present an incomplete Android project as runnable.
